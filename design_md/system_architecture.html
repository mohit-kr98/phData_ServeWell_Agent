Triage agent

Single LLM call classifies the raw ticket into one of three routes.

  • Bedrock · Nemotron Nano 3 30B
L1_GUIDED
L2_ESCALATION
NON_IT

Resolution agent

Tool-calling loop (max 5 turns) over the retrieval and lookup tools, ending in one action. A forced initial search_knowledge_base call plus a forced get_system_spec lookup (keyed off the ticket's system_version field) run automatically before the agent gets control — grounding and spec context are guaranteed, not optional.

  • OpenAI-compatible tool calling via invoke_model
Guardrails
  • Must call search_knowledge_base before any answer — no un-grounded replies
  • 2 failed searches → auto escalate_to_l2
  • 2 troubleshooting replies required before it may escalate for any other reason
